Instructions:
1. Analyze the profile content, focusing on the "Headline", "Experience", "About", and "Contact Info" sections.
2. Identify the person's CURRENT role and CURRENT company.
3. Look for any email addresses or phone numbers mentioned in the text (e.g., "Contact me at...", "email: ...").
4. If the person has multiple current roles, choose the primary one (usually the top one).
5. Return the data in valid JSON format.
6. If the company, role, or contact info is not found, use null.
7. NEVER return "Unknown Company" or "Unknown Role" as a string. Use null instead.

JSON Structure:
{
    "name": "Full Name",
    "company": "Current Company Name",
    "role": "Current Job Title",
    "company_linkedin_url": "URL to company LinkedIn page (if available, else null)",
    "email": "Email address if found (else null)",
    "phone": "Phone number if found (else null)"
}

Examples:

Input:
"John Doe - CTO at TechCorp | Ex-Google..."
Experience:
CTO
TechCorp · Full-time
Jan 2020 - Present · 3 yrs 5 mos

Output:
{
    "name": "John Doe",
    "company": "TechCorp",
    "role": "CTO",
    "company_linkedin_url": null,
    "email": "john.doe@techcorp.com",
    "phone": null
}
