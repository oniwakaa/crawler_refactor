Vision and Goals

This project aims to orchestrate batch B2B lead generation using advanced agent LLMs for web crawling, enrichment, and validation.

- Goal: Automate identification, extraction, and verification of B2B SaaS leads (Name, Role, LinkedIn, Company, Domain, Email, Phone) with minimal human intervention.
- Core features: Robust fallback crawling, shared state between agents, scalable architecture (cloud/local) using Agno and Kilo Code conventions.
